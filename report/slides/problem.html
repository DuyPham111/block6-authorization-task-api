Token hợp lệ vẫn lộ dữ liệu người khác

$ curl /tasks/A1 -H "Bearer <token Alice>"

HTTP/1.1 200 OK · task của project Alpha

$ curl /tasks/B1 -H "Bearer <token Alice>"

HTTP/1.1 200 OK · lộ dữ liệu project Beta

{"id":"B1","projectId":"beta",
 "title":"Kế hoạch ra mắt Beta",
 "description":"Dữ liệu nội bộ của project Beta"}

Ba điều kiện của IDOR/BOLA

  1. Client gửi object ID
  2. Token hợp lệ nên qua xác thực
  3. Server không kiểm quan hệ giữa người gọi và object

Alice không thuộc project Beta. Starter chỉ kiểm token và scope.

Đây là lỗi ban đầu, em chạy thật bằng curl, output nằm trong docs/evidence/v1-idor-curl-before.txt. Alice là Owner của Alpha, token hoàn toàn hợp lệ. Alice đọc A1 thì đúng. Nhưng chỉ cần đổi ID thành B1 là đọc được dữ liệu nội bộ của project Beta. Đủ ba điều kiện của IDOR/BOLA: ID do client gửi, token hợp lệ, và server không kiểm quan hệ giữa người gọi với object. Thông điệp chính: xác thực đúng không có nghĩa là được phép.
