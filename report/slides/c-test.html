21

Kiểm thử bằng Jest và Supertest. Supertest gọi HTTP thật vào app mà không mở cổng, nên request đi qua đủ middleware, route, service, policy. Mỗi phiên bản em viết test trước, rồi dùng test-against.sh lấy src của tag cũ chạy bộ test mới để thấy đỏ, lưu thành file before; sửa xong lưu file after. Test từ chối kiểm cả dữ liệu không đổi, vì một lỗi hay gặp là ghi rồi mới báo lỗi. Test kiểm mã cụ thể 403 hay 404 theo quy ước, chặt hơn tiêu chí "403 hoặc 404" của đề. Kiểm tra ngược: biến thể decide luôn deny trượt 51 trên 70 test; nếu chỉ chấm 403 hoặc 404 thì bản sai vẫn qua 11 trên 17 oracle. Không chọn Postman vì khó chạy trên code của tag cũ và output không gắn commit. Không chỉ unit test vì không chứng minh route thật đi qua policy; nhóm có cả hai loại.
