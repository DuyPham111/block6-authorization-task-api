Phần demo trực tiếp. Một, npm run check: kiểm kiểu và chạy 84 test trong vài giây. Hai, npm run demo: mở localhost:3100/demo, chọn người gọi rồi chạy từng kịch bản hoặc cả 21 kịch bản; ô response hiện quyết định của PDP lấy từ audit log, bảng dữ liệu cho thấy request bị từ chối không làm đổi gì; mở thêm /docs để thấy Swagger UI. Ba, demo-idor.sh: Alice đọc A1 được 200, B1 bị 404. Bốn, test-against.sh: cùng bộ test V1 đỏ trên code starter, tức test thật sự bắt được lỗi. Năm, nếu có Docker: docker compose up, rồi gọi /health. Muốn tự thử thì in token bằng npm run token rồi gọi curl, hoặc dán vào Authorize trên Swagger.
