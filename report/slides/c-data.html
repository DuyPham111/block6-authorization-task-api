Dữ liệu chạy trong RAM, nạp từ data/seed.json. Trọng tâm của bài là logic phân quyền, nên nhóm không muốn máy chấm phải cài cơ sở dữ liệu. resetDb chạy trước mỗi test nên 84 test độc lập, cả bộ khoảng 2 giây. Dataset tách ra file JSON để nộp kèm như mẫu của môn, sửa dataset không phải đụng code. Service và policy không phụ thuộc cách lưu, đổi sang SQL chỉ cần sửa db.js. Block 5 nhóm chọn node:sqlite vì cần transaction thật để chứng minh đổi code một lần; Block 6 không có yêu cầu transaction nào. Đánh đổi: chưa đo hiệu năng JOIN với dữ liệu lớn. Với DB thật, bước kiểm rồi ghi có cửa sổ TOCTOU, xử lý bằng UPDATE có điều kiện hoặc transaction, đúng nội dung Block 7.
