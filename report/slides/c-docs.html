Block 6 · Authorization & Access Control · docs/openapi.yaml

22

Tài liệu API là đặc tả OpenAPI 3.1 viết tay trong docs/openapi.yaml, xem bằng Swagger UI tại /docs của server demo. Mỗi endpoint ghi scope cần có, policy action, và các mã lỗi 401, 403, 404, 400, 409. Thầy có thể bấm Authorize, dán token lấy từ trang demo, rồi Try it out gọi thật. Điểm nhóm thêm: test D1 đọc danh sách route trực tiếp từ Express router rồi so với đặc tả; thêm route mà quên tài liệu, hoặc tài liệu ghi route không tồn tại, thì test đỏ. Không chọn swagger-jsdoc vì phải rải YAML trong comment của route. Không chọn Postman collection vì không phải chuẩn mở. Redoc đẹp nhưng không thử request được. Swagger chỉ có trên server demo, không có trong image Docker.
