Có hai cách triển khai. Cách một: npm ci rồi npm start, Node 22 đọc file .env bằng process.loadEnvFile có sẵn, chỉ khi file tồn tại, nên không cần thư viện dotenv. Cách hai: Docker. Image dựa trên node:22-alpine cho nhỏ, chỉ cài dependency production bằng npm ci --omit=dev, chạy bằng user node chứ không phải root, có HEALTHCHECK gọi /health, và đóng server gọn khi nhận SIGTERM. Image đặt NODE_ENV=production nên thiếu JWT_SECRET thì app không khởi động; docker compose cũng dừng ngay nếu chưa đặt biến này. Thư mục demo bị loại khỏi image, nên production không có /dev/token. Không chọn image node:22 đầy đủ vì lớn hơn nhiều. Không dùng PM2 hay Kubernetes vì vượt phạm vi một API in-memory. Đánh đổi: dữ liệu in-memory nên chỉ chạy được một replica.
